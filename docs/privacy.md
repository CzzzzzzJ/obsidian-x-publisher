# 麦田发布助手 · 隐私政策

更新日期：2026-11-14

麦田发布助手（以下简称「插件」）是一个在你自己的浏览器里运行的发布填写工具。

## 我们收集什么

**什么都不收集。** 插件没有服务器，不向开发者或任何第三方发送你的数据。

## 插件在本机处理的数据

- 你选择的本地文件夹（Obsidian 库、视频发布目录）的访问授权，只保存在浏览器本地（IndexedDB）。
- 读取你指定的笔记、图片、`publish.json`、视频和封面文件，只用于填写到你自己打开的平台页面。
- 填写进度和设置保存在 `chrome.storage.local`。

## 权限用途

| 权限 | 用途 |
|---|---|
| `debugger` | 把本地视频、封面文件交给各平台的上传框（大文件不经过页面内存），并用真实键盘、鼠标事件输入文字 |
| `scripting` | 在 X 长文编辑页插入内容 |
| `tabs` | 在后台打开各平台的上传页 |
| `sidePanel` | 侧边栏界面 |
| `storage` | 保存设置和进度 |
| `notifications` | 填写完成后通知你 |
| 各平台域名 | 只在这些创作者后台页面里填写：B站、小红书、抖音、视频号、YouTube、X |
| `127.0.0.1:8765` | 可选的本机开发桥接，只在「加载已解压的扩展程序」时启用，不连接外网 |

## 不做的事

不读取、不上传你的账号密码和 Cookie；不替你点「发布」；不做点赞、评论、私信、关注等互动操作。
