- 名称：麦田发布助手
- 类别：工作效率 / 工具
- 语言：中文（简体）
- 隐私政策网址：https://github.com/CzzzzzzJ/mdldm-maitian-publisher/blob/main/docs/privacy.md
- 主页：https://github.com/CzzzzzzJ/mdldm-maitian-publisher

## 简短说明（≤132 字符）
麦田工作台的发布引擎：把一期视频的标题、正文、封面和定时一次填进你常用的视频平台上传页，也能把 Obsidian 笔记写进 X 长文。只填写，发布由你自己点。

## 详细说明
给多平台发视频、在 X 写长文的创作者。

【视频多平台分发】
- 每期视频一个工程目录：成片、封面、publish.json（各平台标题、正文、标签、定时）
- 支持 B 站、小红书、抖音、视频号、YouTube 和 X：在后台打开上传页，传视频和封面，填好标题正文和话题，设好定时
- 发前校验：字数上限、必带标签、国内平台不放链接和微信号
- 只填写，最后的「发布」由你自己点

【X 长文】
- 直接读取本地 Obsidian 库，按顺序插入标题、封面、段落、小标题、引用、列表、图片
- 插完逐段核对，漏掉的自动补回

【和麦田一起用】
麦田是开源的多平台发布与数据工作台，可以定时调度本插件、发完自动取链接、每天采集各平台数据。

插件不收集任何数据，不存账号密码。

## 权限说明（审核表单「单一用途」与「权限理由」）
单一用途：把用户准备好的视频和文案填写到用户自己的创作者后台上传页。
- debugger：DOM.setFileInputFiles 把本地大视频文件交给上传框；Input 事件输入文字。
- scripting：X 长文编辑页插入内容。
- tabs：后台打开上传页。
- 各平台 host 权限：只在这些上传页工作。
